# LangGraph Multi-Agent Workflow

## Overview
Demonstrates how to build stateful AI workflows using LangGraph.

## Features
- TypedDict State
- StateGraph
- Nodes
- Edges
- Workflow Execution

## Agents Implemented
- JD Analyst
- Experience Mapper
- Behavioral Interviewer
- Technical Interviewer
- Brain Evaluator

## Learning Outcomes
Understand orchestration of multiple AI agents using shared state.
